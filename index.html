What it shows: A stacked area chart where each colour band represents one clock-hour of the day. The combined height of a column equals the total number of events in that period. Use the Bars toggle to switch to a stacked bar view.

How to read it: Hover over a column to see the exact count for every hour. When the Cumulative toggle is on, a red line on the right axis shows the running total of all events.

Milestones: When enabled, a dashed vertical line marks each bucket in which the running total first reached the next multiple of the chosen increment. Because buckets group several events together the total can jump past a multiple, so the line sits at the first bucket equalling or exceeding it.

What to look for: Tall columns mark high-activity periods. The colour mix reveals which hours of the day drive the volume. A steepening cumulative slope signals acceleration; a flattening slope signals slowdown. The Type toggle shades each column's full height by its most common record type, so runs of one dominant type stand out as a single-coloured band.

Activity heatmap

What it shows: A grid where each cell's darkness encodes the event count for a specific time slot within a period. X-axis = time period (day / week / month); Y-axis = sub-slot (hour of day / weekday / day of month).

How to read it: Darker cells = more events. Hover a cell to see the exact count and coordinates.

What to look for: Dark columns mark busy periods overall. Dark rows reveal time slots that are consistently active. Isolated dark cells are one-off spikes worth investigating.

Slot load distribution

What it shows: For each time slot (e.g. hour of day), this heatmap shows how often that slot reached a given event count across all periods in the selected range. X-axis = time slot; Y-axis = event count per slot; cell darkness = number of periods with that count.

How to read it: Hover a cell for exact figures. The Y-axis only includes count values that actually occurred — gaps in Y mean those counts were never observed.

What to look for: A dark cell at a single Y value for a slot = that slot almost always produces the same count (predictable). Cells spread across a wide Y range for a slot = high variability. A dark row = a count level consistently observed across many slots. Blank slots = no events ever occurred at that time.

Time between events

What it shows: A box-and-whisker plot of the gap (in hours) between consecutive events, grouped by the selected bucket period.

How to read it: The box spans the IQR (25th–75th percentile); the centre line is the median; whiskers extend to the full range; red dots are outliers. Hover for exact statistics.

What to look for: A tight, low box = events arrive at a consistent, frequent pace. A tall box or many outliers = irregular bursts with long quiet stretches in between. A rising median over time = events are becoming less frequent.

Event clustering

What it shows: A scatter plot of the number of qualifying event clusters found in each period of the selected bucket size. A cluster is a run of consecutive events where the gap between each event and the next never exceeds the configured maximum, and the run contains at least the configured minimum number of events.

How to read it: Each point is one period (day / week / month); its height is the number of clusters found in that period. Adjust the spinboxes to tighten or loosen the clustering definition.

What to look for: Periods with multiple clusters indicate repeated bursts of rapid-fire activity, as opposed to a single long burst or scattered isolated events.
